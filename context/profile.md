# Learner Profile

It should contain information that changes slowly.

Do not use this file to track current learning progress. Current progress belongs in `PROGRESS.md`, and the active learning scope belongs in `CURRENT_LEVEL.md`.

## Learning preferences

The preferred learning approach is:

- project-driven;
- incremental;
- evidence-based;
- practical;
- concept-first rather than tool-first;
- focused on the next reachable step;
- resistant to oversized roadmaps.

Avoid:

- large technology checklists;
- excessive certification-driven planning;
- studying advanced topics without a current need;
- defining detailed multi-year plans;
- treating course completion as proof of competence.
