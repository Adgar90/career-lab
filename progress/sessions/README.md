# Session Snapshots

This folder contains compact snapshots of learning sessions.

Use the naming convention:

```text
YYYY-MM-DD-topic.md
```

Snapshots are compact summaries, not conversation transcripts.

Each snapshot should include:

- focus;
- starting point;
- work done;
- key learning;
- evidence;
- open gaps;
- agreed status changes;
- next.

Snapshots are created only after human validation of the session closure.
